# DV1677 Grupp 2 - Frontend

Frontend byggd med React och Vite för hantering av dokument.

## Länkar
- **Driftsatt Frontend (GitHub Pages):** [https://Haniawatah.github.io/dv1677-ht26-grupp2-frontend/](https://Haniawatah.github.io/dv1677-ht26-grupp2-frontend/)
- **Backend API:** [https://dv1677-data.nplab.bth.se/api/documents](https://dv1677-data.nplab.bth.se/api/documents)

## Kör projektet lokalt

1. Installera beroenden: `npm install`
2. Starta utvecklingsservern: `npm run dev`

**Miljövariabler:**

| Miljövariabel | Förklaring | Exempel |
|---|---|---|
| VITE_API_URL | Repository variable för att koppla mot backend-API | [https://dv1677-data.nplab.bth.se](https://dv1677-data.nplab.bth.se) |
